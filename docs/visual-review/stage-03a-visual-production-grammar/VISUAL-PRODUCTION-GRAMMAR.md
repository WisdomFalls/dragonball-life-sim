# U7 Saiyan Visual Production Grammar

The manifest is the production contract for biological identity, PERSON-owned learned behavior, CURRENT_STATE, TRANSFORMATION, EQUIPMENT and PRESENTATION. It avoids full-raster combinatorics by resolving every trait through an explicit strategy and presentation tier. Semantic compositing preserves independently owned anatomy and equipment; pose substitution replaces only the posed component art.
