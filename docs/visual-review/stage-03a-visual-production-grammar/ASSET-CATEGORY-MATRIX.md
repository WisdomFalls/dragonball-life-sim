# Asset-category matrix

| Strategy | Use | Avoid |
|---|---|---|
| Authored geometry | silhouettes, structural frames, hair, face, tails, authored pose families | Cartesian full-body variants |
| Palette | pigmentation, undertones, illumination, hair coloration | geometry duplication |
| Semantic overlay | scars, markings, equipment, tattoos, acute state | destructive merges |
| Derived geometry | developmental expression, definition | free-form raster deformation |
| Directional components | laterality/silhouette-critical traits | automatic mirror assumptions |

Naive full-raster multiplication of frame × 12 proportion axes × muscle × fat × age × hair × tail × directions × poses is unbounded. Production uses component families, palette resolution, overlays, age families, transformation modifiers, pose families and explicit ownership/depth.
