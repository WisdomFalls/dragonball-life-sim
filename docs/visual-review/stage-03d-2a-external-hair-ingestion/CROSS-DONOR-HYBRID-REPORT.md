# Stage 03D.2E cross-donor hybrid proof

Donor B `xv2-xenodimension-black-sister-011` imported successfully through ProjectXIR 0.0.6 in Blender 2.92 without ESK. It is one mesh (`HAIR_Top`) with 1,747 vertices and 2,477 polygons, bound to `b_C_Head`; evaluated bounds are `(-0.206876,-0.109575,0.294700)` to `(0.205860,0.130174,0.598746)`. Normalization uses `+Z` up, `-Y` front, `+Y` back, `-X` anatomical LEFT, `+X` anatomical RIGHT.

The selected swap module is the donor’s single frontal/crown mesh as a provisional `front_fringe`; no deformation or topology edits were applied, and adaptation is identity translation/rotation with uniform scale 1. The resulting hybrid combines derived HUM_015 modules with the selected Black Sister mesh. This is mechanically attachable but artistic compatibility remains uncertain because the donor is a long twin-tail form.

Artifacts include `hair-a-hum015-front.png`, `hair-b-black-sister-011-front.png`, `hybrid-01-front.png`, `hybrid-01-semantic-regions.png`, `hybrid-01-compatibility.json`, and `hybrid-01.blend`. Verdicts: `SECOND_DONOR_IMPORT=GREEN`, `SECOND_DONOR_NORMALIZATION=GREEN`, `COMMON_SEMANTIC_GRAMMAR=YELLOW`, `CROSS_DONOR_GEOMETRIC_COMPATIBILITY=YELLOW`, `CROSS_DONOR_ARTISTIC_COMPATIBILITY=YELLOW`, `MODULAR_3D_HAIR_PIPELINE=YELLOW`.
