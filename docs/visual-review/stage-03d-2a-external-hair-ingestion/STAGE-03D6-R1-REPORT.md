# Stage 03D.6-R1 — Hair palette art-direction correction

The six semantic roles and approved Luceus master structure are unchanged. This revision changes only role colors. Each of the five profiles now has independently art-directed values for depth, temperature, saturation, contrast, and highlight intensity; no universal grayscale tint or hue shift is used.

Profiles: `natural_black`, `dark_brown`, `super_saiyan_gold`, `super_saiyan_blue`, `silver_white`. Natural Black is the current default candidate and uses near-black/cool charcoal values with separated dark roles. The other four are capability demonstrations only. They do not define completed transformation hair states: `NaturalHairIdentity != TransformationHairForm`; future transformations may change geometry, palette, both, or neither.

The regenerated native PNGs and `luceus-palette-profile-comparison.png` preserve identical dimensions, alpha masks, occupied coordinates, role assignment, contour, and registration. Metadata remains in `hair-palette-profiles.json`.
