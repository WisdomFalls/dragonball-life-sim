# U7 Saiyan skin palette catalogue

35 deterministic semantic palettes resolve `7 bands × 5 undertones` through six semantic ramp entries: outline, deepest shadow, shadow, base, light and highlight. Palette resolution is applied only through the skin semantic mask; it never creates duplicate anatomy geometry. Very Light retains shadow steps; Very Deep retains separated base/light/highlight steps.

Renderer tiers preserve identity while allowing compact gameplay ramps. UV and temporary state modify current presentation; aura/environment illumination occurs last and never mutates inherited baseline pigmentation. Congenital markings remain independent BODY-owned overlays.
